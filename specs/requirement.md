## Goal
เป็นเว็บไซต์ที่ทำขึ้นมาเพื่อดูข้อมูลของตัอนิเมะ/มังงะ/นิยาย/ตัวละครอนิเมะที่เราสนใจ โดยในเว็บไซต์จะมีรายการต่างๆมากมาย มี
การแบ่งตามประเภทของแนวอนิเมะหรือมังงะ และต้องการให้เป็นศูนย์รวมของคนชอบการ์ตูน

## User Interactive
### Main Feature
- user สามารถเข้าสู่ระบบ/สมัครบัญชีใหม่ได้ โดยใช้ username และ password ในการเข้าสู่ระบบ
- มีหน้า Profile ที่แสดงข้อมูลของผู้ใช้ มีสถิติบอกว่าเราสนใจแนวไหนหรือดูแนวไหนเป็นหลักแสดงเป็นกราฟเรดาร์ และแสดงโพสต์ที่ user โพสต์ลงไป
- มีหน้าที่สามารถดูได้ว่า user กดชอบอะไรไว้บ้าง ซึ่งเจ้าของบัญชีสามารถแก้ไขหรือลบได้ แต่คนอื่นๆสามารถเข้ามาดูได้อย่างเดียว
- สามารถกดเลือกรายการอนิเมะ/มังงะ/นิยายที่สนใจแล้วจะรายละเอียดของเรื่องนั้นๆ ได้แก่ ต้นฉบับมาจากประเทศอะไร มาจากมังงะ/อนิเมะ หรือนิยาย, ปีที่ออก, ทำขึ้ขึ้นนมาโดยใคร, มีกี่ตอน/เล่ม, สมมติกำลังลังเลือกอนิเมะถ้ามังงะ/นิยาย/เกมที่เกี่ยวข้องก็ให้แสดงด้วย, แสดงรายชื่อละครทั้งหมดในเรื่อง, ถ้ามีหลายซีซันและหลายมูฟวี่ให้แสดงลำดับการดูว่าดูอันไหนก่อนหลัง, collection รวมรูปของตัวละคร, รายชื่อเพลง, รายชื่อช่องทางโซเชียลของ official
- กดเลือกตัวละครที่ชอบโดยจะแสดงข้อมูลของตัวะลครทั้งหมด ได้แก่ รายละเอียดข้อมูลส่วนตัวของตัวละคร, สถานที่เกิด, รายละเอียดครอบครัว, ความสัมพันธ์กับตัวละครต่างๆ(ถ้าเป็นตารางความสัมพันธ์ได้ยิ่งดี), รายชื่อเกม/หนัง/เพลง หรืออื่นๆที่เกี่ยวข้อง, และมี collection รวมรูปของตัวละคร
- admin สามารถกดเพิ่ม, แก้ไขหรือลบตัวละคร/อนิเมะ/มังงะ/นิยาย นั้นๆได้
- user สามารถกดชอยตัวละครหรือเรื่องนั้นๆที่ตัวเองชอบได้ แล้วมันจะไปแสดงในบัญชีเราว่าเราชอบอะไรบ้าง

### Community Feature
- ผู้ใช้สามารถสร้างและดูโพสต์ที่เกี่ยวกับอนิเมะได้ ซึ่งในโพสต์สามารถมีได้ทั้ง Text, image, Video ได้ ห้ามมีการแนบไฟล์อื่นๆ
- เจ้าของโพสต์สามารถ CRUD โพสต์ได้
- แนะนำเพื่อนที่มีสไตล์คล้ายๆหรือเหมือนกัน

### Chat Feature
- สามารถห้องแชทรวมได้ ซึ่งสามารถเลือกได้ว่าจะเป็น private หรือ public
- สามารถกด join หรือ leave ได้
- สามารถส่งข้อความ, เสียง, วิดีโอ, รูปภาพ และไฟล์ต่างๆได้ แต่ไม่เกิน 50MB
- สามารถแชทส่วนตัวได้

## User Experience & Edge Cases (ประสบการณ์ใช้งานและเงื่อนไขพิเศษ)

- **Responsive Design**: หน้าตาแอปพลิเคชันต้องปรับการแสดงผลให้อ่านและใช้งานง่ายทั้งบนคอมพิวเตอร์และสมาร์ตโฟน
- **Long Text Handling**: กรณีชื่อรายการยาวมาก ข้อความต้องขึ้นบรรทัดใหม่อย่างสวยงาม ไม่ล้นหลุดขอบจอ
- **Empty State**: หากยังไม่มีรายการใด ให้แสดงข้อความต้อนรับสั้น ๆ เช่น "ยังไม่มีรายการ เริ่มบันทึกรายรับ-รายจ่ายแรกของคุณได้เลย!"
